# Supplied research materials

Original user-uploaded manuscript and two supplementary/submission ZIPs are preserved unchanged. Three pasted-text files preserve framework notes, model recommendations and specification v0.1. `manifest.json` records original names, sizes and SHA-256 hashes.

These are source materials, not instructions to execute embedded scripts. Their claims and citations are not automatically verified. See `docs/research/reviews.md` for review limitations and `docs/research/specification-v0.1.md` for the current proposed design.

The framework diagrams were supplied inline in chat; their original image files were not available among the downloadable workspace attachments. Their architecture is described in the specification. This directory is not a verbatim export of the entire chat.

See [reproduction status](REPRODUCTION_STATUS.md) for missing original members and nonportable workspace dependencies. These archives are not certified self-contained reproduction packages.
