# One-command reviewer-response campaign

For the complete campaign, independent actor/reward replay, partition diagnosis,
portable kit and formatted reports, run from the repository root:

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 /workspace/lans-venv/bin/python tools/controller_review/run_reviewer_work.py --publish
```

The core campaign alone, using the prepared Python3.10 CPU environment:

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 /workspace/lans-venv/bin/python tools/reviewer_campaign/run.py --publish
```

The command freezes source/model/protocol hashes, runs causal supervisor contracts,
six paired25k PPO pilots, exact actor export, a mirrored864-episode development
comparison, conditional held-out confirmation, real-process worker fault/timing
tests, native Webots interface validation and an evidence-linked response/draft.
It commits and pushes each completed verified stage to the current named branch.
No force push, main-branch merge, original-file overwrite or extra training is used.

Rerun the same command to resume completed stages. Changed frozen inputs require a
new output directory. Partial failed training/evaluation folders are preserved and
require investigation; the runner does not silently delete/retry them.

## Scientific scope

- Original residual architecture: LQR always contributes; PPO proposes bounded
  corrections. Full-command PPO/LQR switching is not this campaign.
- Scratch and fine-tuned PPO receive equal additional25k steps per seed; existing
  causal supervised pretraining is extra budget and is compared separately.
- Twenty normalized channels, with pending-output/forecast/service-oracle channels
  fixed to zero in both training/runtime. Delivery occurs before observation.
- Exact bounded residual fusion replaces the historical clipped-candidate blend.
- Balanced predictor includes heading and command movement; three good control
  ticks and bounded weight increases define recovery. These are explicit runtime
  rules, not a formal logic proof or a proven new neuro-symbolic algorithm.
- Fresh canonical noise and initial state mirror physically left/right. Repeated
  ticks/mirrors are not independent training seeds. True heading and actuator
  metrics accompany lateral error for every episode.
- The simple latency-gain comparator is an explicitly documented reconstruction.
  It is not an exact reproduction of a published algorithm or every original
  manuscript ablation. Matching published algorithms remains pending.
- No externally imposed CPU delay penalty is claimed to train faster inference.

## What one command cannot manufacture

Physical sensor-to-actuator measurements require actual hardware. A finite cloud
timing run cannot prove WCET or guaranteed100Hz; misses are reported as failures.
Formal nonlinear safety, complete primary-reference verification and a matched
published-method reproduction remain explicit open items. The generated paper is
an evidence draft, not a submission-ready manuscript or an assertion that all12
reviewer comments are resolved. No messages are sent to editors/reviewers.

## Evidence

Each output contains protocol/source snapshots, trained endpoints and initialization,
raw per-episode traces, independent audits, timing/fault/native telemetry, stage
status and reviewer-response/revised-manuscript drafts. Confirmation remains
unopened if the prespecified development criteria fail; no post-result tuning.
